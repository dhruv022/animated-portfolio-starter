# 🎨 Animated Portfolio Starter - React + Vite

A **minimal yet powerful React + Vite template** with Hot Module Replacement (HMR) and ESLint rules pre-configured — perfect for building **stunning animated portfolios** quickly.

[🔗 Live Preview](https://animated-portfolio-starter-five.vercel.app/)

---

## ⚡ Features

* ⚛️ Built with **React 18** and **Vite** for ultra-fast development
* 🔄 **Hot Module Replacement (HMR)** for instant feedback
* 🛠 ESLint pre-configured for **clean, maintainable code**
* 🚀 Simple workflow to **build, push, and deploy**
* 🎨 Ready for **animated portfolio projects**

---

## 💻 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the project live.

---

## 📦 Build & Push Code

### 1. Create Production Build

```bash
npm run build
```

### 2. Push to Main Branch

```bash
git add .
git commit -am "Your commit message"
git push origin main
```

---

## 🚀 Deploy to Production

```bash
npm run deploy
```

Your project will be live immediately after deployment.
